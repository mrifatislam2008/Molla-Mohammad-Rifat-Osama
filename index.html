PROFILE OVERVIEW

Hello, I'm Rifat.

Molla Mohammad Rifat Osama is a Bangladesh-based technology enthusiast and developer. I am interested in understanding how digital systems work, building useful software and learning how to make technology more secure and accessible.

My areas of focus include cybersecurity, ethical hacking, authorized penetration testing, red-team concepts, white-hat security practices, Android application development, website development and API projects. I also explore Python, Linux and mobile development workflows.

I study black-hat techniques as threat knowledge to better understand attacker behavior and defensive security. Any security testing should be performed only on systems I own or have explicit permission to assess.
